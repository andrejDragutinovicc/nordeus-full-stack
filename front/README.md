# RPG Run Frontend

A React + Vite frontend for a turn-based RPG run.

## Features
- Main menu with Start Run
- Map screen with 5 encounter cards
- Hero stats and move list
- Turn-based battle screen with backend integration
- Battle log and result handling
- Restart button and loading/error states

## Run locally
1. Install dependencies:
   ```bash
   npm install
   ```
2. Start dev server:
   ```bash
   npm run dev
   ```
3. Open the local Vite URL and ensure backend is running at `http://localhost:8080`.
